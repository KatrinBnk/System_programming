# Тест-кейсы для двухпросмотного ассемблера (Лаба 2)

Набор команд (по умолчанию):

| Имя    | Код | Длина | МКОП (прямая) | МКОП (относит.) | МКОП (без адр.) |
|--------|-----|-------|---------------|-----------------|-----------------|
| JMP    | 1   | 4     | 05            | 06              | —               |
| LOADR1 | 2   | 4     | 09            | 0A              | —               |
| LOADR2 | 3   | 4     | 0D            | 0E              | —               |
| ADD    | 4   | 2     | —             | —               | 10              |
| SAVER1 | 5   | 4     | 15            | 16              | —               |
| INT    | 6   | 2     | —             | —               | 18              |

МКОП = `Code * 4 + AddressingType` (0=без адр., 1=прямая, 2=относительная)

---

## 1. ex_forward_ref.txt — Множественные опережающие ссылки (прямая)

**Проверяет:** корректную работу ТСИ с forward references + таблицу настройки (перемещений).

### Исходный код

```
PROG START 100h
     JMP NEXT
     LOADR1 A1
     LOADR2 A2
NEXT ADD R1 R2
     SAVER1 B
     INT 0
A1 WORD 10
A2 WORD 20
B WORD 1
     END 100h
```

### Первый проход

| Адрес  | МКОП/Дир. | Операнд    | ip после |
|--------|-----------|------------|----------|
| PROG   | START     | 000100     | 0x100    |
| 000100 | 05        | NEXT       | 0x104    |
| 000104 | 09        | A1         | 0x108    |
| 000108 | 0D        | A2         | 0x10C    |
| 00010C | 10        | R1 R2      | 0x10E    |
| 00010E | 15        | B          | 0x112    |
| 000112 | 18        | 00         | 0x114    |
| 000114 | WORD      | 00000A     | 0x117    |
| 000117 | WORD      | 000014     | 0x11A    |
| 00011A | WORD      | 000001     | 0x11D    |

**ТСИ:** NEXT=0x10C, A1=0x114, A2=0x117, B=0x11A

### Второй проход (ожидаемый результат)

```
H PROG 000100 00001D
T 000100 04 0500010C
T 000104 04 09000114
T 000108 04 0D000117
T 00010C 02 1012
T 00010E 04 1500011A
T 000112 02 1800
T 000114 03 00000A
T 000117 03 000014
T 00011A 03 000001
M 000100
M 000104
M 000108
M 00010E
E 000100
```

**Таблица настройки:** 000100, 000104, 000108, 00010E (4 M-записи — все прямые команды)

## 2. ex_backward_ref.txt — Обратные ссылки с отрицательным смещением (относительная)

**Проверяет:** отрицательные смещения в дополнительном коде (FFFFXX), отсутствие M-записей для относительной адресации.

### Исходный код

```
PROG START 100h
A1 WORD 10
A2 WORD 20
B WORD 1
LOOP LOADR1 [A1]
     LOADR2 [A2]
     ADD R1 R2
     SAVER1 [B]
     JMP [LOOP]
     INT 0
     END 100h
```

### Первый проход

| Адрес  | МКОП/Дир. | Операнд | ip после |
|--------|-----------|---------|----------|
| PROG   | START     | 000100  | 0x100    |
| 000100 | WORD      | 00000A  | 0x103    |
| 000103 | WORD      | 000014  | 0x106    |
| 000106 | WORD      | 000001  | 0x109    |
| 000109 | 0A        | [A1]    | 0x10D    |
| 00010D | 0E        | [A2]    | 0x111    |
| 000111 | 10        | R1 R2   | 0x113    |
| 000113 | 16        | [B]     | 0x117    |
| 000117 | 06        | [LOOP]  | 0x11B    |
| 00011B | 18        | 00      | 0x11D    |

**ТСИ:** A1=0x100, A2=0x103, B=0x106, LOOP=0x109

### Вычисление смещений

| Команда      | Адрес цели | Адрес след. | Смещение  | Доп.код (24 бит) |
|--------------|-----------|-------------|-----------|-------------------|
| LOADR1 [A1]  | 0x100     | 0x10D       | −13 (−0xD)| FFFFF3            |
| LOADR2 [A2]  | 0x103     | 0x111       | −14 (−0xE)| FFFFF2            |
| SAVER1 [B]   | 0x106     | 0x117       | −17 (−0x11)| FFFFEF           |
| JMP [LOOP]   | 0x109     | 0x11B       | −18 (−0x12)| FFFFEE           |

### Второй проход (ожидаемый результат)

```
H PROG 000100 00001D
T 000100 03 00000A
T 000103 03 000014
T 000106 03 000001
T 000109 04 0AFFFFF3
T 00010D 04 0EFFFFF2
T 000111 02 1012
T 000113 04 16FFFFEF
T 000117 04 06FFFFEE
T 00011B 02 1800
E 000100
```

**Таблица настройки:** пустая (нет M-записей — все команды относительные)

## 3. ex_self_jump.txt — Самопереход (offset = −4)

**Проверяет:** граничный случай — команда прыгает на саму себя; смещение = −4 = FFFFFC.

### Исходный код

```
PROG START 100h
LOOP JMP [LOOP]
     INT 0
     END 100h
```

### Первый проход

| Адрес  | МКОП/Дир. | Операнд | ip после |
|--------|-----------|---------|----------|
| PROG   | START     | 000100  | 0x100    |
| 000100 | 06        | [LOOP]  | 0x104    |
| 000104 | 18        | 00      | 0x106    |

**ТСИ:** LOOP=0x100

### Вычисление смещения

Адрес цели = 0x100, адрес след. = 0x104, смещение = 0x100 − 0x104 = −4 → FFFFFC

### Второй проход (ожидаемый результат)

```
H PROG 000100 000006
T 000100 04 06FFFFFC
T 000104 02 1800
E 000100
```

**Таблица настройки:** пустая

## 5. ex_data_heavy.txt — Насыщенная данными программа

**Проверяет:** все типы директив (WORD, BYTE числовой, BYTE C-строка, BYTE X-строка, RESB, RESW); метки данных используются как операнды прямых команд.

### Исходный код

```
PROG START 0
S1 WORD 255
S2 BYTE 12h
S3 BYTE C"Hi!"
S4 BYTE X"FF01"
S5 RESB 4
S6 RESW 2
     LOADR1 S1
     LOADR2 S2
     SAVER1 S1
     INT 0
     END
```

### Первый проход

| Адрес  | МКОП/Дир. | Операнд   | Размер | ip после |
|--------|-----------|-----------|--------|----------|
| PROG   | START     | 000000    | —      | 0x000    |
| 000000 | WORD      | 0000FF    | 3      | 0x003    |
| 000003 | BYTE      | 12        | 1      | 0x004    |
| 000004 | BYTE      | C"Hi!"    | 3      | 0x007    |
| 000007 | BYTE      | X"FF01"   | 2      | 0x009    |
| 000009 | RESB      | 04        | 4      | 0x00D    |
| 00000D | RESW      | 02        | 6      | 0x013    |
| 000013 | 09        | S1        | 4      | 0x017    |
| 000017 | 0D        | S2        | 4      | 0x01B    |
| 00001B | 15        | S1        | 4      | 0x01F    |
| 00001F | 18        | 00        | 2      | 0x021    |

**ТСИ:** S1=0x000, S2=0x003, S3=0x004, S4=0x007, S5=0x009, S6=0x00D

### Второй проход (ожидаемый результат)

```
H PROG 000000 000021
T 000000 03 0000FF
T 000003 01 12
T 000004 03 486921
T 000007 02 FF01
T 000009 04
T 00000D 06
T 000013 04 09000000
T 000017 04 0D000003
T 00001B 04 15000000
T 00001F 02 1800
M 000013
M 000017
M 00001B
E 000000
```

Пояснения:
- `486921` = ASCII: H(48) i(69) !(21)
- RESB 4 → длина 04, без данных
- RESW 2 → длина 06 (2 × 3), без данных

**Таблица настройки:** 000013, 000017, 00001B

## 7. ex_numeric_operand.txt — Числовой адрес в 4-байтовой команде

**Проверяет:** исправленный баг — числовой операнд (не метка) в 4-байтовой команде; НЕ попадает в таблицу настройки (абсолютный адрес не нуждается в перемещении).

### Исходный код

```
PROG START 100h
     JMP 150h
     LOADR1 200h
     INT 0
     END 100h
```

### Первый проход

| Адрес  | МКОП/Дир. | Операнд | ip после |
|--------|-----------|---------|----------|
| PROG   | START     | 000100  | 0x100    |
| 000100 | 05        | 000150  | 0x104    |
| 000104 | 09        | 000200  | 0x108    |
| 000108 | 18        | 00      | 0x10A    |

**ТСИ:** пустая

### Второй проход (ожидаемый результат)

```
H PROG 000100 00000A
T 000100 04 05000150
T 000104 04 09000200
T 000108 02 1800
E 000100
```

**Таблица настройки:** пустая (оба адреса абсолютные — перемещение не требуется)

До исправления бага этот пример вызывал исключение `LabelNotFound` во втором проходе, т.к. `GetSymbolicName("000150")` возвращало null.

## 8. ex_next_instr_jump.txt — Переход на следующую команду (offset = 0)

**Проверяет:** граничный случай нулевого смещения при относительной адресации.

### Исходный код

```
PROG START 100h
     JMP [NEXT]
NEXT ADD R1 R2
     INT 0
     END 100h
```

### Первый проход

| Адрес  | МКОП/Дир. | Операнд | ip после |
|--------|-----------|---------|----------|
| PROG   | START     | 000100  | 0x100    |
| 000100 | 06        | [NEXT]  | 0x104    |
| 000104 | 10        | R1 R2   | 0x106    |
| 000106 | 18        | 00      | 0x108    |

**ТСИ:** NEXT=0x104

### Вычисление смещения

Адрес цели = 0x104, адрес след. = 0x100 + 4 = 0x104, смещение = 0x104 − 0x104 = 0 → 000000

### Второй проход (ожидаемый результат)

```
H PROG 000100 000008
T 000100 04 06000000
T 000104 02 1012
T 000106 02 1800
E 000100
```

**Таблица настройки:** пустая
